## 📌 Sobre o Projeto

A **Memolândia** é um jogo educacional interativo desenvolvido para estimular habilidades cognitivas através da gamificação.

O projeto apresenta uma experiência de aprendizado baseada em associação visual, onde o jogador precisa encontrar pares entre símbolos, emojis e palavras.

A aplicação foi criada com foco em tornar o aprendizado mais divertido, intuitivo e acessível, utilizando elementos de jogos para incentivar memória, atenção e concentração.

# 🎮 Como Funciona

O jogador deve encontrar os pares correspondentes no tabuleiro.

Exemplo:

```text
🐶 → Cachorro

🍎 → Maçã

⭐ → Estrela
```

Durante a partida:

1. As cartas começam ocultas.
2. O jogador seleciona duas cartas.
3. O sistema verifica se existe uma correspondência.
4. Caso o par esteja correto, as cartas permanecem abertas.
5. Caso contrário, elas retornam ao estado inicial.
6. Ao encontrar todos os pares, o jogador recebe uma conquista.

# 🧩 Arquitetura da Aplicação

O funcionamento do jogo segue o fluxo:

```text
Inicialização
      ↓
Embaralhamento das cartas
      ↓
Renderização do tabuleiro
      ↓
Usuário seleciona carta
      ↓
Usuário seleciona segunda carta
      ↓
Comparação dos pares
      ↓
Par correto?
      ↓
Sim → Mantém cartas abertas + Feedback
      ↓
Não → Fecha cartas novamente
      ↓
Todos os pares encontrados?
      ↓
Modal de conclusão
```
